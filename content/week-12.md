The homepage is the art direction's proof. If the direction only exists on the moodboard, this is where it shows.

## Due this week

### Homepage: desktop + mobile

- Both breakpoints, built from components and variables
- Real content throughout
- Reflow decisions documented

## Session plan

01. **From wireframe to layout** — Your Week 6 wireframe, now with the system applied. What changed and why.
02. **Build — mobile** — Mobile first, using components and variables only. Auto Layout throughout.
03. **Build — desktop** — Expand. Grid, breakpoint decisions, and what earns more space.
04. **Crit** — Pin both. The room checks: does this look like the named direction, or like a template?

## In-class activity: Homepage, both breakpoints

1. Build mobile first, from components. If you're drawing rectangles, something's missing from the system.
2. Use real content — real product names, real copy lengths, real imagery treatment.
3. Expand to desktop and document each reflow decision.
4. Compare against your moodboard side by side. Name three places the direction is visible.

## Working with AI this week

- “Here's my homepage section order. Which audit finding does each section answer? Where's the gap?”
- Don't paste AI-generated copy into a screen without editing it — default marketing voice reads as default marketing voice.
