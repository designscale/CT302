A moodboard isn't decoration — it's a design argument. Every image is evidence for a direction, and every direction has to translate into UI decisions you can name.

## Due this week

### Art direction proposal

- Creative brief summary
- 2–3 named directions with taglines
- 3–5 visual principles each
- Annotated moodboard, 12–20 references per direction
- Mood-to-UI translation table
- A recommendation

## Session plan

01. **Creative brief summary** — Restate audience, problem and goals in one slide. The direction has to answer this.
02. **Two or three named directions** — Give each a name and a tagline — “Calm Authority,” “Playful Precision.” Label them: safe / stretch / bold.
03. **Moodboard construction** — 12–20 images per direction, sourced across layers: color, typography, imagery style, texture, motion. Not all UI — if every reference is a website, you'll copy instead of create.
04. **Annotate the why** — Callouts on every reference. “The warm indirect lighting here translates to low-density UI with generous padding and soft shadows.”
05. **Mood → UI translation** — A table: feeling on the left, specific UI decision on the right. Corner radius, contrast, density, image treatment.

## In-class activity: Two directions, argued

1. Name each direction and write its three to five visual principles.
2. Build the moodboard by layer, not as one undifferentiated grid.
3. Write the annotation callouts — silent grids score as Emerging at best.
4. Fill the mood-to-UI translation table for the direction you're recommending.

## Working with AI this week

- “Give me four contrasting art directions for [brand], each with a name, three principles, and a color and type point of view.”
- “What's the most predictable visual direction for this category? I want to know what to avoid.”
- Whatever AI proposes, find the version of it that's specific to your brand. Generic ‘modern minimal’ is the default it reaches for and the default that scores lowest.

## Evidence to log

**Creative Art Direction**. Annotated style matrix and mood-to-asset translation log
**Prompt Architecture**. The concept-exploration prompts and what you rejected from them
