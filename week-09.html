Week 09 · Thursday, October 29 · Phase 2 — Design & Presentation

Art Direction & Moodboard

Creative brief summary; 2–3 named directions with brief AI-assisted concept exploration; 3–5 visual principles; annotated moodboard connecting mood to specific UI decisions.

A moodboard isn't decoration — it's a design argument. Every image is evidence for a direction, and every direction has to translate into UI decisions you can name.

Due this week

Art direction proposal

  • Creative brief summary
  • 2–3 named directions with taglines
  • 3–5 visual principles each
  • Annotated moodboard, 12–20 references per direction
  • Mood-to-UI translation table
  • A recommendation

Session plan

01Creative brief summary
Restate audience, problem and goals in one slide. The direction has to answer this.
02Two or three named directions
Give each a name and a tagline — “Calm Authority,” “Playful Precision.” Label them: safe / stretch / bold.
03Moodboard construction
12–20 images per direction, sourced across layers: color, typography, imagery style, texture, motion. Not all UI — if every reference is a website, you'll copy instead of create.
04Annotate the why
Callouts on every reference. “The warm indirect lighting here translates to low-density UI with generous padding and soft shadows.”
05Mood → UI translation
A table: feeling on the left, specific UI decision on the right. Corner radius, contrast, density, image treatment.

In-class activity: Two directions, argued

  1. Name each direction and write its three to five visual principles.
  2. Build the moodboard by layer, not as one undifferentiated grid.
  3. Write the annotation callouts — silent grids score as Emerging at best.
  4. Fill the mood-to-UI translation table for the direction you're recommending.

Working with AI this week

This is the one place AI concept exploration is invited — briefly. Generate directions to react against, then build the proposal by hand. Creative Art Direction explicitly scores whether you overrode AI defaults.

Prompts to start from

  • “Give me four contrasting art directions for [brand], each with a name, three principles, and a color and type point of view.”
  • “What's the most predictable visual direction for this category? I want to know what to avoid.”

What to verify

  • Whatever AI proposes, find the version of it that's specific to your brand. Generic ‘modern minimal’ is the default it reaches for and the default that scores lowest.
